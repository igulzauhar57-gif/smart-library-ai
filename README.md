# SMART LIBRARY AI
М. Әбенова атындағы ЖББМ үшін QR және штрих-кодтарды тану және кітаптарды есепке алу жүйесінің демонстрациялық жобасы.

## Орнату (Windows)
1. Python 3.10+ орнатыңыз.
2. Осы папкада терминал ашып, `py -m pip install -r requirements.txt` орындаңыз.
3. `py app.py` орындаңыз.
4. Браузерден `http://127.0.0.1:5000` ашыңыз.

## Маңызды
- Жүйе Flask + SQLite + OpenCV арқылы жұмыс істейді. `library.db` автоматты жасалады.
- Камерамен браузерде сканерлеу `BarcodeDetector` қолдайтын браузерлерде ғана жұмыс істейді. OpenCV серверде жүктелген суреттегі QR кодты таниды; штрих-код OpenCV нұсқасындағы barcode модуліне байланысты.
- `static/covers/` ішіне өзіңіздегі 10 мұқаба файлын дәл бұрынғы атауларымен көшіріңіз.
- Бұрынғы кітапханаңыздағы PDF сілтемелері бұл пакетке енгізілмеген: оларды құқықтық рұқсаттарын тексеріп, бөлек байланыстыру қажет. `books` кестесіндегі `pdf_url` бағаны осыған арналған.
- Бұл жоба бұрынғы GitHub Pages сайтының орнына жарияланбайды. Flask серверін іске қосу қажет; GitHub Pages Python/SQLite серверін орындамайды.
- Бұл — жергілікті демонстрациялық прототип. Оқырман деректері сақталады; интернетке ашық орналастырмас бұрын авторизация, HTTPS, деректерді қорғау және резервтік көшіру қажет.
